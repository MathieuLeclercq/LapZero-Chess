\begin{tcolorbox}[enhanced, colback=grisfond, colframe=gris!50,
  boxrule=0.5pt, arc=2pt, width=0.88\textwidth]
\small
Ce document raconte comment la recherche MCTS de LapZero-Chess est passee
d'un coeur CPU a huit, pourquoi cette transformation a pris la forme de
vagues, comment elle a ete mise au point sous contrainte de correction, et
ce que les mesures en disent. Il s'adresse a un lecteur familier du projet
ou du domaine, et peut se lire d'un bout a l'autre comme un recit technique.
Toutes les valeurs proviennent de campagnes conservees dans
\code{out/multicore/} ; les commits cites sont dans l'historique Git du
depot.
\end{tcolorbox}
\vspace{1cm}
\end{titlepage}
