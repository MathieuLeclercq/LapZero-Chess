\begin{tcolorbox}[enhanced, colback=grisfond, colframe=gris!50,
  boxrule=0.5pt, arc=2pt, width=0.88\textwidth]
\small
Ce document raconte comment la recherche MCTS de LapZero-Chess, quatre fois
plus lente par position que le self-play a reseau et materiel identiques, a
retrouve le niveau du self-play en corrigeant une seule chose : la forme du
lot envoyee a ONNX Runtime. Il decrit la demarche de mesure qui a isole la
cause, la correction, les pistes essayees et refusees, et ce que les chiffres
disent du plafond restant. Toutes les valeurs proviennent de campagnes
conservees dans \code{out/multicore/} ; les commits cites sont dans
l'historique Git du depot.
\end{tcolorbox}
\vspace{1cm}
\end{titlepage}
